重要说明：EchoMusic 是开源项目 EchoMusic 的非官方 HarmonyOS 移植版本，以 GPL-3.0 协议开源，仅供个人学习与技术交流使用，不用于商业用途。本应用与任何音乐平台均无官方关联，不提供、不存储、不传播任何音频文件，音乐内容版权归原平台及版权方所有。

本隐私政策依据《中华人民共和国个人信息保护法》等法律法规编写，完整说明本应用如何收集、使用、存储、共享和保护您的个人信息与设备数据。请您在使用前仔细阅读。使用本应用即表示您已了解并同意本政策；若您不同意，请停止使用并卸载本应用。

一、核心原则

  1. 无自建服务器：我们没有自建后端、云端数据库或运营账号体系，不会把您的个人信息上传到由开发者控制的服务器，我们无法查看您的账号密码。
  2. 本地优先：账号凭证、设置、播放记录、缓存与日志主要保存在您设备的应用沙箱内。
  3. 最小必要、目的限定：仅在实现对应功能所必需的范围内处理数据，不用于本政策未列明的其他目的。
  4. 可选而非强制：不登录账号、不授权可选权限，仍可正常浏览、搜索与播放大部分内容。
  5. 无广告与画像：不集成第三方广告、统计、推送或用户画像 SDK，不出售个人信息，不将个人信息用于广告营销或自动化决策。

2.2 关于敏感个人信息的特别说明

麦克风采集的环境音频与系统内录音频可能包含环境人声，属于敏感个人信息。我们对此采取以下限制：

  • 仅在您主动触发「听歌识曲」并逐次完成系统授权后采集，绝不在后台、锁屏或您未使用时采集；
  • 仅在识别请求期间临时处理，不写入文件、不建立录音库、不进行声纹识别或身份关联；
  • 识别结束即释放并删除，不留存、不用于曲目识别以外的任何目的；
  • 您可以随时拒绝或撤回授权，拒绝后仅该识别功能不可用，不影响其他功能。

2.3 我们明确不收集的信息

通讯录、短信、通话记录、精确或模糊位置信息、日历、生物特征信息、健康与运动数据、设备标识符（IMEI、OAID、AAID、Android ID 等）、剪贴板历史记录、屏幕画面内容、浏览历史与用户画像标签。本应用不申请与播放、识别无关的权限，不读取您的私人文件，除非您主动选择该文件。

3.2 关于安装包内适配层模板预置权限的说明

本应用基于华为 Electron for OpenHarmony 运行时（web_engine）构建。该运行时面向通用桌面应用，其配置文件中预置了一批与本应用功能无关的权限声明，在打包时会被合并进安装包，包括：定位（LOCATION、APPROXIMATELY_LOCATION、LOCATION_IN_BACKGROUND）、相机（CAMERA）、蓝牙（ACCESS_BLUETOOTH）、生物认证（ACCESS_BIOMETRIC）、陀螺仪 / 加速度计（GYROSCOPE、ACCELEROMETER）以及窗口、打印、证书管理等系统能力权限。

对于上述模板预置权限，EchoMusic 未调用相关接口，未在运行时向您申请授权，也不收集相应数据。 您可在系统设置中核验：本应用运行时实际向用户申请的仅为麦克风权限与系统录屏授权。我们计划在后续版本中精简这些冗余声明。若您对安装包内声明有疑问，可通过第九节的方式联系我们，或直接在开源仓库查阅源码与构建配置。

3.3 设备数据

除上表所列，本应用不读取设备标识符、不扫描已安装应用列表、不读取系统剪贴板历史、不采集屏幕画面。本地运行日志中的设备型号与系统版本仅用于您自行排查问题，保存在本机，不自动上传。

四、我们如何使用您的信息

我们仅在下列目的范围内使用信息：提供歌曲搜索、播放、歌词匹配与播放队列；在您登录后同步第三方平台的歌单与收藏；在您主动触发时完成曲目识别；保存您的偏好设置；在出现错误时供您本地排障。

我们不会将您的信息用于：广告投放、精准营销、用户画像、自动化决策、训练模型、出售或出租给第三方，以及本政策未列明的任何其他目的。

五、我们如何共享、委托处理与公开披露

  1. 无自建后端：我们没有服务器，不会把您的个人信息上传给开发者，也不存在开发者侧的委托处理方。
  2. 必要的第三方请求：为提供播放、搜索、登录与识别服务，本应用会直接向对应的第三方音乐平台公开接口或曲目识别服务发起 HTTPS 请求。请求中仅包含完成该次功能所必需的数据（如搜索关键词、登录令牌、音频片段）。该部分数据由服务提供方按其自身隐私政策处理，我们无法控制其处理行为，建议您在登录或识别前阅读相应服务提供方的隐私政策。
  3. 不出售、不共享给广告商：我们不出售、不出租、不与任何广告或数据服务商共享您的个人信息。
  4. 无第三方 SDK：本应用不集成第三方广告、统计、崩溃上报或推送 SDK。运行时依赖的 HarmonyOS 系统组件与开源库均在设备本地运行，不向第三方回传数据。
  5. 公开披露的例外：仅在法律法规要求、司法机关依法定程序要求，或为保护您与他人的生命、财产安全等合法权益所必需时，我们才可能披露必要信息。本应用无云端数据可披露，实际涉及的信息以您设备上的本地数据为限。

六、我们如何存储和保护

数据 存储位置 保留期限 删除方式
登录令牌与账号资料 设备应用沙箱 至您退出登录或清除应用数据 应用内退出登录 / 系统「清除应用数据」/ 卸载应用

保护措施：所有本地数据依赖 HarmonyOS 提供的应用沙箱隔离与访问控制；网络传输使用 HTTPS；账号令牌不以明文写入日志；本应用开源，源码可公开核验。我们不在云端保存副本，因此卸载应用或清除应用数据后，本地信息即被删除且无法由我们恢复。

关于跨境：我们不设置云端存储、不主动进行跨境传输。您向第三方服务发起的请求，其数据流向由该服务决定，相关合规义务由其自行承担。请注意互联网环境并非绝对安全，请妥善保管您的设备与账号。

七、您的权利

您对个人信息的处理享有以下权利，均可自行操作，无需向我们申请：

  • 不登录、不授权：不登录账号、不授予麦克风与录屏授权，即可使用浏览、搜索与播放等基本功能；
  • 撤回授权：在「系统设置 → 应用和服务 → 应用管理 → EchoMusic → 权限」中关闭麦克风等权限；
  • 访问与更正：账号资料、播放记录与设置均在应用内可见可改，或直接查看应用沙箱数据；
  • 删除与注销：本应用无云端账号，退出登录并在系统设置中「清除应用数据」即可删除全部本地个人信息；卸载应用效果相同；
  • 拒绝识别：在「听歌识曲」中直接取消，或拒绝系统的「允许使用你的屏幕」确认框；
  • 询问、投诉与建议：按第九节方式联系我们，我们将在 15 个工作日内答复。

八、未成年人保护

本应用面向一般用户，不面向未满 14 周岁的儿童提供专门服务，不会主动收集未成年人的个人信息，也不包含针对未成年人的内容推荐、付费或社交功能。

若您是未成年人的监护人，发现被监护人向我们提供了个人信息，或对其信息处理有疑问，请通过第九节方式联系我们，我们会协助删除相关数据。若您是未成年人，请在监护人陪同下阅读本政策并使用本应用；涉及第三方账号登录时，请务必先取得监护人同意。

九、第三方服务与链接

  • 本应用通过公开接口使用第三方音乐平台的内容服务，并可能调用第三方曲目识别服务；这些服务适用其各自的隐私政策与用户协议。
  • 应用内「设置 → 关于」及本政策包含指向 GitHub 开源仓库的外部链接，用于查看源码、更新日志与提交反馈。GitHub 适用其自身隐私政策。
  • 音乐内容与第三方账号服务均由相应平台提供，我们对其内容、可用性与数据处理行为不承担责任。建议您在向其提供信息前阅读其隐私政策。

十、本政策的更新

如功能、权限或法律法规要求发生变化，我们会更新本政策，并修改页首「最近更新」日期，同时在应用内「设置 → 关于」中提供最新版本的入口。涉及个人信息处理目的、方式或范围的重大变更时，我们会在应用内以适当方式提示您。若您继续使用更新后的版本，视为接受更新后的政策；若不同意，可停止使用并卸载应用。

本政策的历史版本可在开源仓库的提交记录中查阅。
